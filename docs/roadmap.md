# AlgoPilot Roadmap:L1 → L5

> 原则:每一步都先有"不可博弈的判据",再谈自动化程度。等级定义见 philosophy.md。

- [x] 棘轮主循环:观察→假设→补丁→评审→sandbox→判定,三态台账
- [x] 智能组织三角色:研究员/工程师(LLM 双档)/评审员(纯代码)
- [x] 策略库/失败库沉淀 + 晨报
- [x] **端到端对齐最终交付**:delivery.py 会话仿真(模型自选曝光 + 真实因果 pCTR
      响应)作为第二道门;rejected_by_delivery 新判定;alignment 兑现率沉淀进
      台账/晨报/研究员观察——离线棘轮走得快,交付门禁走得对
- [x] rec 域装置:合成 CTR(真实交叉信号)+ 稀疏 LR + 10 KNOB(含 `_heat_boost`
      马太效应试探旋钮),单实验 <1s,交付仿真 400 会话确定性可复现
- [x] 防作弊三件套:judge 独立计时、数据指纹、评审黑名单
- [x] 57 项零依赖测试(含交付门禁单测 + 组织全循环端到端)

      兑现率谱系 3.07(特征交叉)/ 0.86(收敛加速)/ 0.078(加轮数)——
      **同样是离线保留,交付价值差 40 倍**,端到端对齐让组织看得见这件事
- [x] 断点续跑:台账接续,不重复 warmup(交付基线自动补测)

## L3 → L3.5:装置升级(2026-11-14 部分达成)

- [x] **真实数据适配器**:prepare.py 检测 `data_raw/train.csv + val.csv`
      (约定列:`label` + `num_*` + 恰好 3 个 `cat_*` 域,Criteo 风格导出改列名即接入);
      manifest 标记 kind=real,model 特征空间自适应(类别域哈希桶 ≤512 防爆炸,

- [ ] **会话化真实回放**:real 数据带会话结构后,delivery.py 升级双模式
      (组内 top-K 曝光 + 真实 label 的命中率),替代合成世界 ground truth
- [ ] rec 域可改范围扩展:允许 rewrite 演化出 FM/DeepFM 结构
      (评审员规则同步升级:维度/耗时护栏约束)
- [ ] elite 复验升级为三连跑 + 区间判定

## L4:高度自动(2026-11-14 达成首批能力)

- [x] **多分支并行**:workers>1,批内多路并行实验(各自独立 sandbox),批末按
      「分叉点结算、最优者合并」串行裁决——merge 决策事件(append-only)记录
      胜者与落选分支,elite 投影由 merge 事件携带可重建;单 worker 行为与串行棘轮
      完全一致。实测:并行路径上交付门禁自然拦下 aggressive-lr(离线 +0.0024、
      交付 CTR +0.0103,但曝光熵 0.68→0.16 生态坍缩)——**单一指标都会放行,
      生态护栏维度起了决定作用**
- [x] 研究员升级:读失败库做归因聚类,动态调整探索方向(mock 的频率换真 LLM 的判断)
      ——**部分达成**:治理秘书(governance)已能把台账教训提炼为组织代码修改提案
- [x] **program.md 自迭代(受限版,L5 前奏)**:`pilot propose` 从台账提炼修改提案
      (mock 规则器确定性 / 真 LLM),红线校验(纯代码:IMMUTABLE 铁律区禁触、
      anchor 白名单、幂等)→ `pilot approve` 人类审批 → 备份生效 → 台账
      program_update 事件。**组织代码本身进入台账,组织的进化有了自己的历史**
- [ ] 时序数据/多场景版装置(支持场景分组评测,主指标按场景加权)
- [ ] 晨报升级:失败归因摘要(LLM report 角色真启用)

## L5:通用智能组织

- [ ] **search 域落地**(蓝本已备):NDCG@10 + query 分组评测,验证列表态指标接入
- [ ] **ads 域落地**(蓝本已备):模拟 eCPM + 竞价仿真,验证博弈性域的护栏设计
- [ ] 三域共享策略库的跨域迁移实验("特征交叉有效"这类经验是否跨域成立)
- [ ] 在线门禁适配器:承接 L3 产物,生成 A/B 实验配置草稿(人类一键审批)
- [ ] 与 AgenticRec 2.0 运行时互通:AgenticRec 管"单次推荐的元决策",
      AlgoPilot 管"算法版本间的迭代"——两个组织,一份台账哲学

## 明确不做(边界即设计)

- 不做在线流量自动调整——上线门禁永远在人类手里(L3 的定义);
- 不做针对评测集的任何优化通道——数据指纹 + 冻结 judge 双保险;
- 不引入重型 agent 框架——循环的每一步都必须可以被一个 jsonl 行解释。
